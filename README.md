**CleanVerify for WooCommerce** is an all-in-one customer verification, anti-fraud protection, quarantine trash recovery, and inactive account cleanup suite for WooCommerce stores. It keeps your store database lean, fast, secure, and free of abandoned zero-order accounts and spam signups.

---

## 📌 Why CleanVerify?

Over time, high-traffic WooCommerce stores accumulate thousands of dormant customer accounts generated by bot registrations, disposable email signups, abandoned carts, or test users. 

These inactive accounts cause:
* **Database Bloat:** Slower database queries, larger SQL backups, and increased hosting overhead.
* **Skewed Analytics:** Distorted customer acquisition costs (CAC) and inaccurate active buyer metrics.
* **Security & Deliverability Risks:** Risk of fake accounts triggering automated welcome drip emails and hurting email domain reputation.

CleanVerify provides an intuitive, high-performance admin dashboard to detect, export, and clean inactive accounts safely while preventing new bot accounts from entering your store.

---

## 🚀 Free Features (Core Edition)

* **🔍 Smart Zero-Order Customer Detection:** Accurately scans for customer-role accounts that have never completed an order. Cross-checks both the customer's WordPress User ID and guest checkout billing emails so past guest shoppers are never falsely flagged.
* **⏱️ Configurable Inactivity Age Buffer:** Filter candidates by account registration age (e.g., older than 30, 60, or 90 days) with 1-click presets so active new shoppers are never touched.
* **📥 Instant CSV Export:** Export filtered or selected customer data to CSV with UTF-8 BOM encoding for out-of-the-box compatibility with Microsoft Excel, Apple Numbers, and Google Sheets.
* **🛡️ Hardcoded Role Safety Shield:** Automatically protects Administrators, Editors, Authors, and Shop Managers from being queried or accidentally modified.
* **⚡ Instant Client-Side Tab Navigation:** Reactive dashboard architecture allowing instant tab switching with zero page reloads and browser history support.
* **🔒 Enterprise Security Standards:** Built strictly with WordPress security best practices, strict nonce validation, `delete_users` capability checks, and confirmation barriers.
* **📦 100% Zero Remote CDN Calls:** All icons, SVGs, styles, and scripts are bundled locally for maximum speed, GDPR compliance, and privacy.

## 📦 Installation

### Via WordPress Admin
1. Download the latest release `.zip` file.
2. In your WordPress admin dashboard, navigate to **Plugins → Add New → Upload Plugin**.
3. Upload the `.zip` file and click **Install Now**.
4. Click **Activate Plugin**.
5. Navigate to **CleanVerify** in your WordPress admin sidebar (positioned right after **WooCommerce**) to access your dashboard.

### Manual Installation via Git
```bash
cd wp-content/plugins/
git clone https://github.com/murshed/cleanverify-for-woocommerce.git
```

## 🛡️ Security & Safety Architecture

1. **Guest Order Cross-Verification:**
   CleanVerify checks both the WordPress User ID on WooCommerce orders (`_customer_user`) and the `_billing_email` meta across all orders. If a user registered an account but previously purchased as a guest using that email, they are recognized as a paying customer and protected.

2. **Strict Capability & Nonce Verification:**
   Every cleanup and export action verifies WordPress nonces (`wp_verify_nonce`) and validates that the current user has the `delete_users` capability.

3. **Zero Remote Network Calls:**
   No third-party CDN scripts, Google Fonts, external SVGs, or tracking pixels are loaded by default in the Free version, guaranteeing compliance with strict data protection regulations.

## ❓ Frequently Asked Questions

#### Does CleanVerify delete customer accounts automatically?
In the Free version, no accounts are ever deleted automatically. Deletion only occurs when you explicitly select accounts and confirm the deletion dialog. CleanVerify Pro provides automated background cron pruning if enabled.

#### What happens to customers who checked out as guests?
CleanVerify safely cross-references the user's account email against all past WooCommerce orders. If an order with that billing email exists (even without being logged in), the account is marked as a purchasing customer and will **not** be flagged.

#### Can I export a customer backup before running a cleanup?
Yes. CleanVerify includes an export tool allowing you to export all filtered candidates or specifically selected accounts to a CSV file (with Excel-compatible UTF-8 BOM encoding) before running any cleanup.

#### Are Administrator and Shop Manager accounts protected?
Yes. CleanVerify includes a role safety shield that explicitly excludes Administrators, Editors, Authors, and Shop Managers from candidate queries and blocks them from deletion even if submitted.
